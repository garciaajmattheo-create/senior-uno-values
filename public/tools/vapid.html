Push notification keys

Setup tool for the administrator. Click the button once, then copy the two keys:

  • Public key → VAPID_PUBLIC_KEY in js/config.js and as a Supabase Edge Function secret.
  • Private key → only as the Supabase secret VAPID_PRIVATE_KEY. Never put it in the website files.

Keys are made in your browser and are not sent anywhere. Keep the private key secret.
